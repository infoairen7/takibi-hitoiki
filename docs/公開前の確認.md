## この確認で見つかって、直したこと（キャラクターを外した後）

別のエージェントに、キャラクターを外した変更全体を見直してもらいました。見つかったものは次のとおり直しました。

1. **以前の版の途中の火を続きから遊ぶと、思い出が「小さく静かな火」・いちばん大きな火 0 になった**：以前の版は火力を記録していなかったため。引き継いだ回は火力で火の様子を決めず、カードにも火力を出さないようにしました。
2. **以前の版で残した思い出を上書きすることがあった**：以前の版で見送って思い出を残した回を、新しい版で続きから開いてもう一度残すと、同じID（seed-日付）の思い出を書き換えていました。新しい版の思い出は `t-` から始まるIDにしました。
3. **以前の版の「生まれた後に火が消えた」見送りが、最後まで見送った回として数えられた**：「早めに休ませた」として扱い、組み方の発見を与えないようにしました。
4. **記録ファイルを読み込んだときの「解放」の知らせ**・**薪の道具箱の「発見N件で」**：以前の版の解放の数（unlockFloor）を含めずに数えていました。含めて数えるようにしました。
5. **最後の10秒の見送りが始まった後に「今日はここまで」を押すと、記録に「途中で見送りました」と残った**：見送りが始まっていれば、そのまま見送るようにしました。
6. **火吹き筒の世話が「風」として数えられていた**（合計の回数は正しい）：火吹き筒として数えるようにしました。
7. **第1段階（出会いの記録だけ）からの移行で、解放が1件多くなる場合があった**：以前の版の数（火を灯す＋会ったキャラ）を超えないようにしました。
8. **画面に「育成」の言葉が残っていた**（再開・一時停止の画面、20分モードの説明）：火の進みの言葉に直しました。

## キャラクターがいた版の確認で見つかって直したこと（記録）

燃焼に関わるものは、今の版にもそのまま入っています。

1. **燃え尽きかけた火が戻らなかった**：底の熾が長く残るようにし、風を送ると熾が明るくなって上の薪を温めるようにしました。炎が消えてから1分半ほどの間なら、薪を置いて風を送れば戻ります。案内も「赤い熾が残っています」と「風を送る」ボタンに変えました。
2. **燃え尽きた後に、燃えているふりの時間が続いた**：熾も火を戻せないほど弱くなったら、その時点から熾火の時間に入り、いつもと同じ長さで自然に見送ります（延長しない）。中薪まで火がつながる前に消えたときは「火が消えました」として、火口からやり直せます。
3. **思い出の画像を作れない端末で、ボタンが止まったままになった**：「画像を作れませんでした。記録と文章は残せます」と出して、記録と文章のコピーができます。
4. **読めない発見の記録**：容量不足で退避できないときは上書きしません。
5. 温まっている途中の薪がある間は燃料切れ・「消えた」に数えない。消えた後に熾から火が戻ったときは世話の道具箱へ。「今回の組合せでもう一度」を続けて使っても風の状態がずれない。
