# 焚き火と、ひと息。 — 公開版 1.0（2026-10-04）

薪を組んで、火を灯して、育てて、熾火を見送る。ブラウザで遊ぶ、10分（または20分）の焚き火のゲームです。最後に、その回の画面から思い出カードを作ります。

## ブラウザで遊ぶ

**https://infoairen7.github.io/takibi-hitoiki/**

スマホでもPCでも、このURLを開くだけで遊べます（GitHub Pages で配信）。記録（発見・アルバム・途中の火）は、そのブラウザの中にだけ保存されます。別の端末やブラウザへ移すときは、メニュー →「設定」→「記録を書き出す」「記録を読み込む」を使ってください。

> **2026-10-04：キャラクターは企画から外しました。** 以前の版（「ギャル火ちゃん」）にいた火の精・おじ火の仲間・会話・問いかけ・図鑑・性格の判定は、画面からもプログラムからも取り除きました。焚き火そのもの（燃え方・道具・場所・発見・思い出）はそのまま残しています。以前の版で遊んだ記録（発見・アルバム・途中の火）は、そのまま引き継げます（下の「以前の版の記録」）。

- 対象：スマホ（縦・横）とPCのブラウザ。WebGL2が必要です。iPhone・iPadは iOS 16 以降の Safari、Android は最近の Chrome、PCは Chrome・Edge・Firefox・Safari 16 以降を想定しています。
- **実機（iPhone・Android・PCの実ブラウザ）では未確認です。** 確認はこの制作環境のヘッドレスChromium（GPUなし・CPU描画）と自動テストで行いました。
- 構成：React 19 + TypeScript + Three.js r186（0.186.1）。3Dの描画（WebGL）と画面のUI（DOM）は分けてあります。全パラメータは `src/game/balance.ts`。

## 一回の流れ（ひと息10分）

| 段階 | 目安（着火から） | 画面 |
|---|---|---|
| 組む | 時間制限なし | 火口・細薪・中薪を置く（組み方の見本4種からも選べる）。場所・焚き火台・時間もここで選ぶ |
| 灯す | — | ライターで火口に火をつける |
| 細薪→中薪へ | 30〜50秒 | 中薪に火が移ると小さな音と、その薪の樹種のひとこと。ここから太薪も選べる |
| 育てる | 〜8分ごろ | 薪を足す・火ばさみで整える・うちわや火吹き筒で風を送る・「しばらく、火を眺める」。強すぎる火・こもった煙・湿った薪・空気不足には、状態の案内と次の操作のボタンが出る |
| 熾火 | 8分12秒（残り18%） | 15秒前に案内。薪の追加が「火を見守る」に変わり、火は熾へ落ちていく |
| 見送り | 9分50秒〜10分 | 火がしずかに消えていく |
| 思い出 | 10分 | 実際の画面から作ったカード（1080×1350）。今夜の火の名前・火の様子・結びの一文・記録。保存・シェア |

- 薪を足さずに燃え尽きたときは、熾も火を戻せないほど弱くなった時点から熾火の時間に入り、いつもと同じ長さ（10分なら約1分50秒）で見送ります（延長しない・責めない）。
- 中薪まで火がつながる前に消えたときは「火が消えました」と出て、火口からやり直せます。
- 途中で「今日はここまで」を選ぶと、15秒かけて火を落として見送ります（引き止めません）。
- 「ゆっくり20分」では、中薪と熾が時間に合わせてゆっくり燃え（火口・細薪の着火は同じ）、熾火・見送りの時刻はほぼ2倍になります。発見に必要な秒数も長さに合わせます。
- 時刻は自動プレイ（`scripts/playbot.ts`）で測った目安です。

## 思い出カード

その回の焚き火の写真（火が育った節目＝火力45・60・75で撮り直し、いちばん大きく育った時の一枚）と、次の内容です。キャラクターや台詞は入りません。

- **今夜の火の名前**（候補12から seed で決まる。思い出の画面で12文字まで変えられる。絵文字を途中で切らない・HTMLとして扱わない）
- **火の様子**（その回の燃え方から一つ）：おだやかな火／よく燃えた火／こまめに世話をした火／小さく静かな火／もう一度立ち上がった火（熾から戻した）／湿った薪の、しっとりした火／燃え尽きるまで見守った火／早めに休ませた火
- **結びの一文**（火の様子ごとに2つの候補から seed で選ぶ。同じ回なら同じ文）
- 薪の樹種 × 場所 × 組み方、育て方、火と過ごした時間、記録（落ち着いた火の時間の割合・いちばん大きな火力・世話の回数）、日付
- 「思い出を残す」でアルバム（端末内・最大100件・お気に入りは保護）へ記録し、PNGを保存。「シェアする」は共有メニュー（非対応なら画像保存と文章のコピー）。キャンセルはエラーにしません。共有の文：`今夜の火：こはく｜おだやかな火｜なら × さくら／森の湖畔 #焚き火とひと息`

## 発見と解放

発見は24件（期限なし・ログイン条件なし）。すべて焚き火のことです。達成すると「新しい発見：…（n/24）」と、解放されたものを知らせます。

- 火を灯す・中薪まで火をつなぐ・風を送って細薪へ火を渡す・太薪に火を入れる・火を大きく育てる・赤い熾から火を戻す（火吹き筒でも）・強すぎる火を落ち着かせる・こもった煙に空気を通す・燃えている薪を火ばさみで組み直す・しめり木に火を入れる・組んだ薪だけで最後まで見送る・ゆっくり20分で最後まで見送る・薪を3種／4種／累計12種使う・4つの組み方それぞれで最後まで見送る・落ち着いた火を続けて眺める・名前をつけた火を記録する・思い出を5つ残す・6種類の場所で思い出を残す。
- 解放：薪12種（はじめ4種、発見2・4・6・8件で2種ずつ）、場所6種（2・4・6・8件）、焚き火台（3・5・7・9件）、装飾8種（10〜20件）、火吹き筒（3件）。
- 解放は循環しません（先に解放が要る発見を除いても8件に届く。自動テストで確認）。

## 実装済み・仮素材・未確認

### 実装済み
- 燃焼シミュレーション（10Hzの固定刻み・決定的）：薪ごとの区間の温度・水分・燃料・熾・灰、空気（配置から計算）、風（うちわ・火吹き筒）、燃え移り、煙、熾火、燃料切れ。描画のFPSが違っても同じ進み（30・60・120fps、揺らぎ・カクつきで一致）。
- 薪12種（燃え方は詳細仕様6章の値）と太さ3種（細薪・中薪・太薪。中薪と太薪はあわせて5本まで）。薪の樹種ごとのひとこと（その回で初めて火が入ったとき）。
- 道具：火ばさみ・うちわ・火吹き筒（得意の違いを自動テストで確認：火がある時はうちわが速く、熾だけの終わりぎわは火吹き筒が届く）。
- 状態の案内：火が強すぎる・煙がこもる・湿った薪・空気不足・燃料が少ない・熾が残っている・新しい薪が温まっている、と次の操作のボタン。
- 場所6種・焚き火台5種・装飾8種、20分モード、今回の組合せでもう一度。
- 思い出カード・アルバム・シェア、記録の書き出し・読み込み。
- 保存と再開（燃えている間は10秒ごと・画面を隠すとき・ページを閉じるとき）。保存できないときは一度だけ知らせ、今までの保存は消さない。
- 音（焚き火・環境音・効果音・BGM。すべてその場で合成する自作の音。音ありで始めたときだけ鳴らす）、振動（指で触る端末）、文字の大きさ、動きを控えめに、描画品質の自動調整、動作チェック、横向きの短い画面の配置、「このゲームについて」（素材と権利・ライセンス全文）。

### 仮素材（差し替えなくても公開できる）
- 湖畔の遠景は承認済み画像F01から切り出した仮素材。ほかの5か所の遠景は、ゲームの中で描いた手作りの仮の背景（画面の選択肢にもそう書いてある）。
- 薪・焚き火台・地面・装飾はプログラムで作った形と模様。音はその場で合成する自作の音。
- 一覧は `public/assets/asset-manifest.json`、ゲーム内「このゲームについて」。差し替えたい素材は `docs/画像素材の依頼.md`。
